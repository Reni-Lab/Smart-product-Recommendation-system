# Smart-product-Recommendation-system
The system should evaluate the trained model and then accept a customer ID or customer details as input. It should generate predictions for available products, calculate their predicted purchase probability, rank the products, and display the Top 5 recommended products.
Language: R ('tidyverse','RMySQL')
Database: MySQL ('shoppingdb')
How to Run this project:
1) Set up database and use commands as mentioned in databasesetup.sql
2) Configure Credentials by opening Reni'sShop.R and updating the connection string with your local MySQL password
3) Run the script in your R environment to train your model and generate recommendations!
